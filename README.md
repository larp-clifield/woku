# woku

## velocity-pasta.cpp — мега-паста CS2 velocity сорсов

**67,600+ строк, всё самое лучшее в одном файле.**

### Содержимое:
1. **velocity-fixed-main** (hackvshack.net) — полный сорс CS2 чита
   - core/features/ — combat (rage/legit), ESP, movement, changer, misc, world
   - core/hooks/ — хук-фреймворк
   - core/rendering/ — меню и рендеринг (xdraw)
   - core/systems/ — bones, hitboxes, prediction, entities, tracing
   - utilities/ — memory, math, addresses, hooking, logging, steam
   - protection/ — паттерн-сканер
2. **cs2-reverse.md** — дока по реверсу CS2 (entity list, bones, weapons, etc.)
3. **rage.cpp** — standalone rage бот ("Пища от ума")
4. **ImGui Menu MemeSense** — фреймворк меню чита (src/)
